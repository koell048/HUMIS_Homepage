# HUMIS website

## Developed as a part of the Fall 2026 Adv Web Design class

This is based on a PDF of an actual design that was used for the University of Utah.

This project did have some mixed difficulty for me. I had a different professor for my Web Design 1 class who definitely did not teach as in-depth on the coding side of things, so some things were less of a review for me. However, if anything was confusing it was mostly due to pace and I was able to watch the Zoom recordings later and catch back up. Some things were definitely review as well, it just took a minute to pull them from memory from two years ago.

I feel like I definitely have a much better understanding of the concepts now, and surprisingly I think the most beneficial thing to really fully grasping the concepts was to fall behind a bit and be forced to catch up on my
own. In class I would think I had something down, but what really taught it to me was having to put it into practice without being told exactly what to do. In the future, I definitely hope to continue using these skills as I think they will be very valuable to add to my portfolio, and I hope to continue practicing when this class is finished so I do not lose all my memory of the skills like I did after my Web 1 class.

In all, this project was very beneficial to me. Despite feeling like there was too much material to possibly remember at times, I found myself able to recall and apply much more than I thought, and actually understand what I was doing.
